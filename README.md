# LCN Bot

Discord-бот для клана LCN, который публикует объявления об ивентах, создаёт ветки, собирает отметки участников и отправляет личные напоминания.

## Функционал

- `/add_reminder`  
  Создаёт объявление или еженедельное напоминание об ивенте.

  Параметры:
  - `weekday` — день события (`1-7`, русский или английский день недели)
  - `time` — время начала события по МСК (`HH:MM`)
  - `remind_weekday` — день публикации объявления (опционально)
  - `remind_time` — время публикации объявления (опционально)
  - `ping_role` — роль сервера для пинга при публикации (опционально)
  - `repeat` — режим публикации: `true` каждую неделю, `false` один раз
  - `title` — заголовок объявления
  - `description` — описание события

- `/list_reminders`  
  Показывает список объявлений: событие, время публикации, режим `weekly/once`, канал, роль для пинга, заголовок и описание.

- `/edit_reminder reminder_id:<id>`  
  Редактирует существующее объявление. Неуказанные поля остаются как были.

  Поля для редактирования:
  - `weekday` — новый день события
  - `time` — новое время начала события
  - `remind_weekday` — новый день публикации
  - `remind_time` — новое время публикации
  - `ping_role` — новая роль для пинга
  - `clear_ping_role` — убрать роль для пинга
  - `repeat` — переключить режим `weekly/once`
  - `title` — новый заголовок
  - `description` — новое описание

  Примеры:
  - `/edit_reminder reminder_id:3 time:17:00`
  - `/edit_reminder reminder_id:3 remind_weekday:среда remind_time:10:00`
  - `/edit_reminder reminder_id:3 repeat:false`
  - `/edit_reminder reminder_id:3 clear_ping_role:true`

- `/delete_reminder reminder_id:<id>`  
  Удаляет объявление по ID.

- `/delete_reminder_list`  
  Позволяет удалить объявление через выпадающий список.

- `/ping`  
  Проверяет, что бот онлайн.

## Объявления

При публикации объявления бот отправляет embed-сообщение с кнопками:
- `✅ Приду`
- `❌ Не приду`

В сообщении видно, кто за что проголосовал. Если пользователь меняет выбор, бот переносит его в другой список.

При публикации бот автоматически создаёт ветку под сообщением. Название ветки строится из даты, времени события и заголовка.

Режимы публикации:
- `repeat:true` — объявление повторяется каждую неделю.
- `repeat:false` — одноразовое объявление. После публикации бот удаляет его из `reminders.json`, и на следующей неделе оно не переносится.

## Личные сообщения

Если в объявлении указан `ping_role`, бот отправляет ЛС участникам этой роли с кнопками `Приду` и `Не приду`. Выбор из ЛС синхронизируется с публичным сообщением в канале расписания.

За 30 минут до начала события бот отправляет дополнительное ЛС всем, кто нажал `✅ Приду`.

Если у пользователя закрыты личные сообщения, бот просто пропускает его и продолжает работу.

## Файлы состояния

- `reminders.json` — список объявлений и расписание публикаций.
- `reminder_votes.json` — голоса пользователей по опубликованным объявлениям.
- `reminder_dispatches.json` — служебное состояние для ЛС-напоминаний за 30 минут.
- `reminder_dm_links.json` — связь между ЛС и публичными сообщениями расписания.

## Настройка

1. Установи Python 3.11+.
2. Установи зависимости:
   - `pip install -r requirements.txt`
3. Заполни `.env`.
4. Запусти:
   - `python bot.py`

## Переменные `.env`

Обязательные:
- `DISCORD_BOT_TOKEN`

Опциональные:
- `DISCORD_GUILD_ID` — ускоренная синхронизация slash-команд на конкретном сервере.

## Discord Developer Portal

Для рассылки ЛС участникам роли нужно включить `SERVER MEMBERS INTENT`:

1. Открой `https://discord.com/developers/applications`.
2. Выбери приложение бота.
3. Открой вкладку `Bot`.
4. В блоке `Privileged Gateway Intents` включи `SERVER MEMBERS INTENT`.
5. Сохрани изменения и перезапусти бота.

## Обновление на сервере

```bash
cd /opt/LCN_bot
git checkout dev
git pull origin dev
source .venv/bin/activate
pip install -r requirements.txt
sudo systemctl restart lcn-bot
```

## Команды systemd

Остановить бота:

```bash
sudo systemctl stop lcn-bot
```

Запустить бота:

```bash
sudo systemctl start lcn-bot
```

Перезапустить бота:

```bash
sudo systemctl restart lcn-bot
```

Проверить статус:

```bash
sudo systemctl status lcn-bot --no-pager
```

Смотреть логи:

```bash
journalctl -u lcn-bot -f
```

## Примечания

- Slash-команды Discord иногда обновляются не мгновенно. Если параметр не появился, подожди немного и заново открой меню `/`.
