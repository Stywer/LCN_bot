# LCN Bot

Discord-бот для клана LCN для работы с таблицей слотов Arma в Google Sheets и напоминаний об ивентах.

## Текущий функционал

- `/sheet` — показывает строки слотов по сторонам (для `Ротация 1`)
- `/sheet_unselected` — показывает только строки, где `Отряд = Не выбран`
- `/occupy row:<номер> count:<число> [side:<1|2>]`
  - в выбранной строке записывает:
    - `Отряд = LCN`
    - `Занято = <число>`
  - `side` нужен, если в одной строке листа две стороны (левая/правая таблица)
- `/ping` — проверка, что бот работает

## Новый функционал: напоминания об ивенте (МСК)

Бот поддерживает еженедельные напоминания и работает по часовому поясу Москвы (`Europe/Moscow`).

- `/add_reminder weekday:<день> time:<HH:MM> [message:<текст>]`
  - добавляет напоминание в текущий канал
  - `weekday` можно указывать как:
    - число `1-7` (`1=ПН`, `7=ВС`)
    - русский день (`понедельник`, `пт`, `воскресенье`)
    - английский день (`monday`, `fri`, `sun`)
  - `time` — время в формате `HH:MM` (24 часа), по МСК
  - если `message` не задан, используется стандартный текст

- `/list_reminders`
  - показывает все настроенные напоминания (день, время, канал, текст)

### Как срабатывают напоминания

- при запуске бот определяет текущее время по МСК
- в фоновом режиме проверяет расписание
- в нужные день/время отправляет сообщение в канал, где напоминание было создано
- напоминания хранятся в файле `reminders.json`

## Настройка

1. Установите Python 3.11+
2. Установите зависимости:
   `pip install -r requirements.txt`
3. Заполните `.env`
4. Подготовьте Google service account и доступ к таблице
5. Запустите:
   `python bot.py`

## Обязательные переменные `.env`

- `DISCORD_BOT_TOKEN`
- `CLAN_NAME` (обычно `LCN`)
- `GOOGLE_SERVICE_ACCOUNT_FILE` (обычно `service_account.json`)
- `GOOGLE_SHEET_ID`
- `GOOGLE_WORKSHEET_NAME`

## Опциональные переменные `.env`

- `START_ROW` (обычно `2`)
- `TABLE_PREVIEW_MAX_ROWS`
- `TABLE_PREVIEW_MAX_COLS`

## Примечания

- Команды Discord могут появляться с задержкой после перезапуска (синхронизация slash-команд)
- Если команда не видна, подождите немного и перезапустите клиент Discord
