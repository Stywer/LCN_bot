# LCN Bot

Discord-бот для клана LCN для работы с таблицей слотов Arma в Google Sheets.

Бот читает таблицу, показывает строки по сторонам (только для `Ротация 1`) и позволяет записывать клан `LCN` и количество участников в выбранную строку.

## Возможности

- Показ строк слотов по сторонам (`/sheet`)
- Отдельный вывод только строк, где `Отряд = Не выбран` (`/sheet_unselected`)
- Запись в выбранную строку:
  - `Отряд = LCN`
  - `Занято = <число>`
- Поддержка выбора стороны (`side`) для строк, где в одной строке листа есть левая и правая таблица

## Команды

- `/sheet`
  - Показывает строки слотов по сторонам (формат для чтения в Discord)
  - Фильтрует таблицы только по заголовку `Ротация 1`

- `/sheet_unselected`
  - Такой же вывод, как `/sheet`
  - Показывает только строки, где в колонке `Отряд` стоит `Не выбран`

- `/occupy row:<номер> count:<число> [side:<1|2>]`
  - В выбранной строке записывает:
    - `Отряд = LCN`
    - `Занято = <число>`
  - Если в одной строке есть две стороны (левая/правая таблица), укажи `side`
  - Примеры:
    - `/occupy row:23 count:8`
    - `/occupy row:23 count:8 side:1`
    - `/occupy row:23 count:8 side:2`

- `/ping`
  - Проверка, что бот работает

## Как работает выбор строк

Бот автоматически распознает в листе таблицы со слотами по заголовкам колонок (`№ отделения`, `Техника`, `Слоты`, `Отряд`, `Занято`) и берет данные только из блоков `Ротация 1`.

## Настройка

1. Установите Python 3.11+.
2. Установите зависимости:
   `pip install -r requirements.txt`
3. Создайте `.env` (или используйте существующий) и заполните значения.
4. Создайте service account в Google Cloud и включите Google Sheets API.
5. Скачайте JSON-ключ service account и положите его в папку проекта (`service_account.json`).
6. Выдайте доступ к Google Sheets таблице для `client_email` из `service_account.json` (права `Editor`).
7. Создайте Discord-бота, получите токен и добавьте его в `.env`.
8. Пригласите бота на сервер с правами `bot` + `applications.commands`.
9. Запустите:
   `python bot.py`

## Переменные окружения (`.env`)

Обязательные:

- `DISCORD_BOT_TOKEN`
- `CLAN_NAME` (обычно `LCN`)
- `GOOGLE_SERVICE_ACCOUNT_FILE` (обычно `service_account.json`)
- `GOOGLE_SHEET_ID`
- `GOOGLE_WORKSHEET_NAME`

Опциональные:

- `START_ROW` (обычно `2`)
- `TABLE_PREVIEW_MAX_ROWS`
- `TABLE_PREVIEW_MAX_COLS`

## Примечания

- Новые slash-команды в Discord могут появляться не сразу (глобальная синхронизация).
- Если команда не видна, подождите немного и перезапустите Discord-клиент.
